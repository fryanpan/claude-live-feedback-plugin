1. Orphan is visible. On the desktop margin it can't be — orphaned threads have no anchor to hang a balloon from, so the margin only ever shows open ones. This drawer is the only place the state that needs action can appear.
2. A no-reply thread stays one line. Its single comment already says everything a summary would; four lines would be three restatements.
3. Resolve without opening. Same ✓ as the expanded card, same handler.
